ASTRA-Redo Architecture & Technical Reference

An interactive, mathematical, and topological walkthrough of the astra-redo.py deep learning pipeline: integrating spatial transcriptomics with CITE-seq ADT proteins and spatial ATAC-seq chromatin peaks via Dual-GCNs, Spot-Adaptive Gated Attention Fusion, and Spatial Potts Markov Random Field Deep Embedding Clustering.

MRF Consensus: Potts Regularized DEC

1. Executive Summary & Problem Setting

Spatial multi-omics co-assays profile transcriptomics alongside auxiliary proteomic or epigenomic markers across tissue microenvironments. Standard autoencoders struggle with modality discrepancy, boundary smearing, and decoupled cluster formation.

Challenge 1 Modality Discrepancy

Gene counts ($3000$ HVGs) and auxiliary modalities (proteins or ATAC peaks) have completely different dynamic ranges, sparsity patterns, and dimensions. Concatenating them raw induces modality dominance.

Challenge 2 Spatial vs. Phenotypic Conflict

Physical proximity does not guarantee cellular identity (e.g. sharp tumor-stroma boundaries). Pure spatial smoothing smears boundaries, whereas pure feature clustering yields noisy "salt-and-pepper" spot artifacts.

Challenge 3 Decoupled Clustering Collapse

Autoencoder reconstruction gradients often drown out clustering objectives. ASTRA-Redo introduces an active two-stage training paradigm where DEC actively steers latent manifolds regularized by spatial Potts consensus.

Antibody-Derived Tag (ADT) Centered Log Ratio (CLR)

Antibody tag counts suffer from non-specific background binding and scale variations. The Seurat-style CLR computes geometric mean across non-zero features per spot, regularized by $10^{-12}$:

$$\mu_{\ln}(x) = \frac{1}{|x|} \sum_{i: x_i > 0} \ln(1 + x_i)$$ $$G(x) = \exp(\mu_{\ln}(x))$$ $$\text{seurat\_clr}(x_i) = \ln\left(1 + \frac{x_i}{G(x) + 10^{-12}}\right)$$

Spatial ATAC-seq Epigenomic Peak Normalization

Chromatin accessibility peak counts are sparse binary indicators. A Term Frequency - Inverse Document Frequency (TF-IDF) transformation down-weights ubiquitously open chromatin regions and amplifies cell-type-specific accessible loci, followed by 50-component PCA.

$$\text{IDF}_j = \frac{N_{\text{spots}}}{\sum_{i=1}^{N_{\text{spots}}} X_{ij} + 10^{-12}}, \quad \text{TF}_{ij} = \frac{X_{ij}}{\sum_{k=1}^{M_{\text{peaks}}} X_{ik} + 10^{-12}}$$ $$\text{TF-IDF}(X)_{ij} = \text{TF}_{ij} \cdot \text{IDF}_j$$ $$Z_{\text{atac}} = \text{PCA}_{50}(\ln(1 + \text{Normalize}(\text{TF-IDF}(X))))$$

8. Dual-Graph Topology & Spatial Adjacency Construction

Implemented in lines 128–186. ASTRA-Redo constructs three distinct graph topologies and an MRF Potts consensus matrix to guide message passing across physical coordinates and functional similarities.

Topology 1 Cosine Feature Graph ($G_{\text{sim}}$)

Built on RNA HVGs ($3000$ dimensions). Nearest neighbors ($k=15$) are identified using cosine distance. Symmetrized: if $j \in \text{kNN}(i)$ or $i \in \text{kNN}(j)$, edge $(i,j) \in \mathcal{E}_{\text{sim}}$. Edge weights equal pairwise cosine similarities.

$$S_{ij}^{\cos} = \frac{x_i \cdot x_j}{\|x_i\|_2 \|x_j\|_2 + 10^{-12}}$$ $$A_{ij}^{\text{sim}} = \mathbb{I}(j \in \text{KNN}(i) \lor i \in \text{KNN}(j)) \cdot S_{ij}^{\cos}$$
Topology 2 Spatial Distance Graph ($G_{\text{dist}}$)

Built on physical tissue 2D coordinates $(x,y)$. Uses Euclidean kNN ($k=15$) and symmetrized via maximum operation: $A_{\text{dist}} = \max(A, A^T)$. Edge weights represent Euclidean distance.

$$d_{ij} = \|(x_i, y_i) - (x_j, y_j)\|_2$$ $$A_{\text{dist}} = \max(A_{\text{knn}}, A_{\text{knn}}^T)$$
Topology 3 Intersection Consensus Graph ($G_{\text{common}}$)

The auxiliary modality (protein/chromatin) propagates solely across the rigorous set intersection:

$$\mathcal{E}_{\text{common}} = \mathcal{E}_{\text{sim}} \cap \mathcal{E}_{\text{dist}}$$ $$W_{ij}^{\text{common}} = 1.0 \quad \forall (i,j) \in \mathcal{E}_{\text{common}}$$

Guarantees that auxiliary omics message passing occurs exclusively between spots that are simultaneously physical neighbors and transcriptomically correlated!

MRF Operator Potts Row-Normalized Spatial Adjacency

Constructed by adding self-loops to physical spatial adjacency and row-normalizing by degree:

$$\tilde{A} = A_{\text{dist}} + I_N$$ $$D_{ii} = \sum_{j=1}^N \tilde{A}_{ij}$$ $$A_{\text{norm}} = D^{-1} \tilde{A}$$

Used during DEC target distribution calculation to smooth cluster assignments locally.

10. Spatial Potts MRF Deep Embedding Clustering

Implemented in lines 211–254. Standard Deep Embedding Clustering (DEC) sharpens cluster assignments using Student's t-distribution but is blind to spatial organization. ASTRA-Redo introduces a spatial Potts Markov Random Field consensus mechanism that injects neighborhood affinity into the target distribution $P$.

1. Soft Assignment Matrix $Q$

Calculates Student's t-distribution similarity between latent embedding $z_i$ and learnable prototype centroids $\mu_k \in \mathbb{R}^{64}$ ($k=1,\dots,K$, with degrees of freedom $\alpha=1.0$):

$$q_{ik} = \frac{\left(1 + \frac{\|z_i - \mu_k\|_2^2}{\alpha}\right)^{-\frac{\alpha + 1}{2}}}{\sum_{k'=1}^K \left(1 + \frac{\|z_i - \mu_{k'}\|_2^2}{\alpha}\right)^{-\frac{\alpha + 1}{2}}}$$
2. DEC Cluster Sharpening ($P_{\text{dec}}$)

Squares probability values to emphasize high-confidence assignments and normalizes by cluster frequencies $\sum_i q_{ik}$ to prevent large clusters from dominating:

$$p_{\text{dec}, ik} = \frac{q_{ik}^2 / \sum_{i=1}^N q_{ik}}{\sum_{k'=1}^K \left(q_{ik'}^2 / \sum_{i=1}^N q_{ik'}\right)}$$
Key Innovation 3. Spatial Potts Neighborhood Consensus ($P_{\text{spatial}}$)

ASTRA-Redo computes spatial neighborhood consensus by taking the matrix product of the row-normalized spatial adjacency $A_{\text{norm}}$ and the soft assignment matrix $Q$:

$$\text{Consensus} = A_{\text{norm}} \cdot Q \in \mathbb{R}^{N \times K}, \quad \text{Consensus}_{ik} = \sum_{j=1}^N (A_{\text{norm}})_{ij} q_{jk}$$

The sharpened target distribution is then exponentiated with the Potts consensus energy scaled by $\lambda_{\text{spatial}} = 0.15$ and renormalized across all clusters:

$$p_{\text{final}, ik} = \frac{p_{\text{dec}, ik} \cdot \exp\left(\lambda_{\text{spatial}} \cdot \text{Consensus}_{ik}\right)}{\sum_{k'=1}^K p_{\text{dec}, ik'} \cdot \exp\left(\lambda_{\text{spatial}} \cdot \text{Consensus}_{ik'}\right)}$$

Finally, the network is trained by minimizing the batch-mean Kullback-Leibler (KL) divergence between $Q$ and $P_{\text{final}}$:

$$\mathcal{L}_{\text{KL}} = \text{KL}(Q \parallel P_{\text{final}}) = \frac{1}{N} \sum_{i=1}^N \sum_{k=1}^K p_{\text{final}, ik} \ln\left(\frac{p_{\text{final}, ik}}{q_{ik}}\right)$$

12. Comprehensive Mathematical Loss Formulation

Implemented in lines 342–378. The optimization objective harmonizes multi-task feature fidelity, spatial contrastive topology preservation, weight sparsity, and clustering entropy.

1. Multi-Task Reconstruction Losses
$$\mathcal{L}_{\text{rec}} = \frac{1}{N} \sum_{i=1}^N \| [X_{\text{RNA}} \parallel X_{\text{ADT}}]_i - \hat{X}_{\text{joint}, i} \|_2^2$$ $$\mathcal{L}_{\text{sim}} = \frac{1}{N} \sum_{i=1}^N \| X_{\text{RNA}, i} - \hat{X}_{\text{sim}, i} \|_2^2$$ $$\mathcal{L}_{\text{dist}} = \frac{1}{N} \sum_{i=1}^N \| X_{\text{RNA}, i} - \hat{X}_{\text{dist}, i} \|_2^2$$ $$\mathcal{L}_{\text{aux}} = \frac{1}{N} \sum_{i=1}^N \| X_{\text{ADT}, i} - \hat{X}_{\text{aux}, i} \|_2^2$$
2. Spatial Regularization Contrastive Loss

Enforces latent cosine similarity between physical neighbors while penalizing similarity between non-neighbors:

$$S_{ij} = \frac{z_{\text{fused}, i} \cdot z_{\text{fused}, j}}{\|z_{\text{fused}, i}\|_2 \|z_{\text{fused}, j}\|_2 + 10^{-12}}, \quad \tilde{S}_{ij} = \sigma(S_{ij})$$ $$\mathcal{L}_{\text{spatial}} = -\frac{1}{2} \left[ \frac{1}{|\mathcal{E}|} \sum_{(i,j)\in\mathcal{E}} \ln(\tilde{S}_{ij}) + \frac{1}{|\mathcal{E}^c|} \sum_{(i,j)\notin\mathcal{E}} \ln(1 - \tilde{S}_{ij}) \right]$$
3. Regularization & Master Objective Equation
$$\mathcal{L}_{\text{reg}} = \lambda_{L_1} \sum_{\theta \in \Theta} |\theta| + \lambda_{L_2} \sum_{\theta \in \Theta} \theta^2 \quad (\lambda_{L_1} = 10^{-4}, \lambda_{L_2} = 10^{-3})$$ $$\mathcal{L}_{\text{total}} = \beta_{\text{curr}} \left( \mathcal{L}_{\text{rec}} + \mathcal{L}_{\text{sim}} + \mathcal{L}_{\text{dist}} + \mathcal{L}_{\text{aux}} \right) + \gamma \mathcal{L}_{\text{spatial}} + \delta \mathcal{L}_{\text{reg}} + \mathbb{I}(\text{Stage 2}) \cdot \lambda_{\text{dec}} \mathcal{L}_{\text{KL}}$$
Hyperparameter Default Value Functional Role
beta ($\beta$) $25.0$ (Stage 1) / $5.0$ (Stage 2) Reconstruction loss weighting; scales joint and branch reconstruction MSE
gamma ($\gamma$) $10.0$ Spatial contrastive loss weighting; maintains tissue neighborhood topology
